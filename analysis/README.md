# Analyses historiques

Ce répertoire conserve les tables agrégées et les scripts qui ont servi à
analyser les deux exécutions DVS-GC. Il est fourni pour la provenance des
résultats, mais ne constitue pas le parcours de reproduction principal.

Certains manifestes CSV enregistrent encore les chemins absolus du serveur au
moment de leur création. Ces chemins sont des métadonnées historiques : les
fichiers individuels auxquels ils renvoient ne sont pas distribués. Les points
d'entrée maintenus et portables sont indiqués dans le `README.md` à la racine.
